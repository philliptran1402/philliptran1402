# 🌍 About Me

I'm a **Software Engineer with 6+ years of experience**, building backend systems where a bug costs money — not just a bad user experience.

Most of my work sits on the **money path**: perpetual DEX backends, lending integrations, reorg-safe indexers, automated signing and settlement. More recently I build **AI agents** that plan and execute on top of that infrastructure.

What I care about:

- ⚡ **DeFi infrastructure** — perps, options, lending, AMMs, RWA, cross-chain messaging
- 🤖 **AI agents for on-chain execution** — intent → strategy → simulation → guardrails → signing
- 🔗 **Reorg-safe data pipelines** — indexers, subgraphs, finality-aware settlement
- 🧠 **Architecture over implementation** — the trade-off and its cost, not just the code

Based in **Da Nang, Vietnam** · growing toward **technical leadership**.

An LLM-driven agent that turns a trading intent into a safe on-chain action.

Features:

- Intent parsing → strategy planning → quoting across venues
- Multi-venue routing and execution orchestration
- Simulation before submission, with a policy layer gating every signature
- Position and PnL tracking, structured run history for review

Tech stack:

- TypeScript / NestJS
- LLM APIs + tool calling
- EVM (viem / ethers.js)
- PostgreSQL, Redis

## 📐 Options / Derivatives Platform

On-chain options infrastructure — where the hard part is risk, not matching.

Features:

- Option series lifecycle: listing by strike/expiry, exercise, cash or physical settlement
- Pricing & risk: implied volatility surface, greeks (delta / gamma / vega / theta) per account
- Collateral & margin for short positions, with liquidation when coverage breaks
- Expiry automation: oracle settlement price, auto-exercise of ITM positions
- Vault strategies (covered call / cash-secured put) with automated roll cycles

Tech stack:

- TypeScript / NestJS, Solidity
- PostgreSQL, Redis
- Oracle price feeds, scheduled settlement workers

## 🔗 Blockchain Event Indexer

High-performance event pipeline built to survive reorgs, not just to be fast.

Features:

- Realtime processing plus paced historical backfill
- Reorg handling via block hash-chain verification and rollback-able schema
- Finality tiers — value-based confirmation policy before data is treated as settled
- Idempotent writes and query APIs for downstream services

Tech stack:

- Node.js, Kafka
- PostgreSQL, Redis
